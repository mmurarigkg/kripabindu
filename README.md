# `Krpa Bindu` 

```
Krpa Bindu is a desktop application created to provide daily remembrance of the
teachings of His Holiness Gopal Krishna Goswami Maharaja.
```

```
The central idea of the program is simple: each day, the application presents a
specific spiritual instruction associated with that date. The application
automatically determines the current date and uses the month and day to find the
corresponding entry in its database. The database is stored separately from the
program itself.
```

```
Main functions
```

# `Daily spiritual guidance.` 

```
When the program is opened, it displays the teaching associated with the current
date. The user can also manually select another date and view the corresponding
teaching.
```

# `English and Russian languages.` 

```
The application supports English and Russian versions of the content and allows
the user to switch between them. The selected language is saved in the program
settings.
```

# `Photographs.` 

```
The application uses a collection of photographs and can display them randomly.
```

```
Devotional music.
```

```
The application includes a collection of bhajans sung by Gopal Krishna Goswami
Maharaja.
```

```
Persistent settings.
```

```
The application maintains user settings such as language, window position, size
and other interface parameters.
```

```
Krpa Bindu — компьютерная программа, созданная для ежедневного памятования
наставлений Его Святейшества Гопал Кришны Госвами Махараджа. Основная идея
программы проста: каждый день пользователь получает определённое духовное
наставление, соответствующее текущей дате. Программа автоматически определяет
текущую дату, использует месяц и день как ключ и находит соответствующую запись
в базе наставлений. База хранится отдельно от программного кода.
```

```
Основные функции
Ежедневное духовное наставление.
```

```
При запуске программа показывает наставление, соответствующее текущей дате.
Пользователь также может выбрать любую другую дату и посмотреть связанное с ней
наставление.
```

```
Русский и английский языки.
```

```
Программа поддерживает русский и английский языки и позволяет переключаться
между ними. Выбранный язык сохраняется в настройках.
```

```
Фотографии.
```

```
Программа использует коллекцию фотографий и показывает их в случайном порядке.
```

```
Бхаджаны и киртаны.
```

```
В программу включена коллекция бхаджанов, исполненных Гопал Кришной Госвами
Махараджем.
```

```
Сохранение настроек.
```

```
Программа сохраняет пользовательские настройки, включая язык, положение и размер
окна и другие параметры интерфейса.
```
